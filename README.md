# Student Success Diagnostic Pipeline (EDA & Feature Engineering)

A data preparation and feature engineering pipeline designed to convert raw student lifestyle and attendance logs into highly predictive indicators for machine learning models.

## 🎯 The WWH Framework
* **WHY:** To build an early warning system that catches academic risk windows before final examinations take place.
* **WHAT:** A modular analytics dashboard blueprint that translates scattered student tracking logs into warning indicators.
* **HOW:** Implemented via Python (Pandas/NumPy/Seaborn) to run multi-panel statistical anomaly profiling and deep feature generation.

## 💡 Key Pipeline Innovations
* **The Academic Speedometer (`study_vs_free`):** Ratios out focused study hours directly against available empty free time to track a student's daily focus pace.
* **Prescriptive Potential:** By comparing midterm gaps against the student's current pace, the metrics give down-stream models the mathematical insight to calculate how much study time adjustments are required to guarantee a passing grade.
* **Risk Buckets:** Bins continuous attendance behaviors into actionable Low/Medium/High risk tiers.
